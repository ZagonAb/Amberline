# Amberline

**Amberline** is a retro‑futuristic theme for Pegasus Frontend with smooth navigation. Organized in three columns (collection bar, game grid, and details panel), it includes:


- 🎨 **13 live-preview color themes**
- 🔍 **First-letter navigation** + progressive scroll
- 🏆 **Built-in RetroAchievements** – achievements, progress & stats
- 📐 **Adaptive 4:3 / 16:9 layouts** with dynamic grids
- 🎮 **Gamepad & keyboard support** *(touchscreens not supported)*
- 🎥 **Full media support** (images, video, auto-scroll descriptions)
- 💾 **State persistence** – restores your last collection and game on launch
